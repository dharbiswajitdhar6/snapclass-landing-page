# SnapClass – Landing Page

The official landing page for **SnapClass AI Attendance System**, designed to introduce the platform, explain its features, and showcase the student and teacher workflows.

## 🌐 Live Website

[Visit SnapClass](https://snapclass-landing-page-liart.vercel.app/)

## ✨ Features

- Modern responsive landing page
- Student journey showcase
- Teacher journey showcase
- AI attendance feature overview
- Technology stack section
- Responsive design for different screen sizes
- Direct access to the AI Attendance application

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Flask
- Jinja2

## 📂 Purpose

This repository contains only the **frontend/landing website** of SnapClass.

The actual AI attendance application is maintained separately.
